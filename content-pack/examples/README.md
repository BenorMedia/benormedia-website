# Examples

`hvac-invoicing-software-commercial-page-outline.md` is the commercial page outline Sergio supplied on 2026-10-07 (a SwipeSimple page). It is the model for the shape and rhythm of every BenorMedia commercial page: header table, eyebrow, benefit-led H1, short intro, two CTA buttons, proof strip, H2 sections of one framing line and a few bullets with an image direction, a "what it should do for you" section, testimonial and reviews direction, accordion FAQ, closing H2 with CTA buttons, and JSON-LD.

It is not BenorMedia content. Match its structure, not its sentences, and never copy anything from it into a page. The checker does not read this folder.

`outlines/` in the pack root shows the same format filled with BenorMedia pages (generated by `node scripts/build-outline.mjs`).
